📜 游戏规则

玩家：3 人，斗地主标准 54 张牌。开局每人 17 张，留 3 张底牌；叫到地主者吃底牌。

叫地主：随机一人先叫，依次叫 0/1/2/3；叫 3 立即结束；若全 0 则重新发牌。

出牌顺序：地主先出。出牌后顺时针轮转 (seat+1)%3；其他两家都不要时上一手领出者重新领出。

合法牌型：单张 / 对子 / 三张 / 三带一 / 三带对 / 顺子（≥5 连张，不含 2/王）/ 连对（≥3 对）/ 飞机带翅膀 / 炸弹（四张）/ 火箭（双王）。

比大小：同型比点数；炸弹大过非炸；火箭最大。

⏱ 出牌计时：每个回合（叫牌 / 出牌）共 60s。前 15s 为思考阶段，禁止操作，服务器会拒绝并返回剩余等待秒数；后 45s 为出牌阶段，可叫牌 / 出牌 / 不要；本人操作完成后立即切到下一位的 60s 计时。超时未操作：叫牌自动 0，出牌自动 pass（如果是领出者则强制出最小单张）。

胜负：先把手牌出完者胜。地主胜则地主赢，农民胜则两个农民赢。

💰 计分：每人每局 -1 积分入场费。基础得分：地主侧 20，农民侧每人 10。倍率 = bid × 2^炸弹 × 2^火箭 × 2^春天，其中：bid = 叫地主分（1/2/3）；炸弹 / 火箭按本局出过的张数翻倍；春天 = 地主胜且农民全程一张未出（地主侧 ×2）；反春 = 农民胜且地主只领出过一墩（农民侧 ×2）。
例：bid=3、2 个炸弹、无春天 → 倍率 12，地主胜每位农民 −120，地主 +240；之后每人再 −1 入场费。

充值：USDT-BEP20（BSC 主网，链 ID 56），1 USDT = 1000 积分，最低 1 USDT。生成订单后请按提示金额（精确到 4 位小数）转账，错链或金额不符不会自动到账。

规则模式 (rule_mode)：builtin 用服务器内置裁判；referee 把判定外包给指定 URL 的 referee agent。

聊天：单条 ≤ 500 字符，历史保留最近 200 条。旁观者只读。

解散房间：仅房主（首位加入者）可解散。解散后房间从大厅消失、所有未完成的回合作废。
